# Copilot Experience

## What Worked Well

1. Copilot helped me create the calculator functions and explained what each function did.
2. Copilot helped me fix several coding errors, especially syntax and indentation problems.
3. Copilot helped me build the menu system for Part 3.
4. Copilot showed me how to test each menu option to make sure it worked.
5. Copilot helped me understand how the equation solver uses brute-force search to find a value for x.

## Challenges

1. At first I was confused about where to put different pieces of code in my file.
2. I accidentally typed Python code into the terminal instead of placing it in the program.
3. I had trouble understanding indentation and the difference between if name == "main" and if _name_ == "_main_".

## My Judgment

One suggestion from Copilot caused an error because I accidentally copied and pasted it in the wrong place. Instead of leaving it, I deleted the incorrect code and rebuilt the bottom part of the program step by step until it worked.

Another issue was when my program showed errors related to indentation. Rather than continuing with broken code, I replaced the menu section with a cleaner version and tested each option one at a time. This helped me better understand how the menu worked and made it easier to find mistakes.

Overall, Copilot helped me complete the project, but I still had to test the code, fix mistakes, and make sure I understood what the program was doing before submitting it.
